安装

一分钟装好

下载并解压

在 Releases 下载 zip，解压到任意文件夹。

打开开发者模式

进入 chrome://extensions 或 edge://extensions，打开「开发者模式」。

加载插件

点「加载已解压的扩展程序」，选中解压出的文件夹，刷新 B 站即可。

隐私

只和 B 站说话

只请求 B 站接口用浏览器里已有的登录状态，和 B 站网页自己的请求一样。

数据只存本地设置和缓存保存在浏览器里，不会离开你的电脑。

开源可查全部代码在 GitHub 上，约 500 行。
