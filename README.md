**B站动态按分组/分区一键筛选**

项目主页：https://kairui-shi.github.io/bilisift/

在 B 站顶栏的「动态」弹窗里加一个筛选栏，按 **关注分组 / 视频分区 / UP主** 只看最近 1～7 天的某一类动态，不用再一个个点进 UP 主页。

- **关注分组**：直接使用你在 B 站设置的关注分组，例如「守望先锋」「音乐」
- **分区**：按视频所属分区自动归类，不需要任何设置
- **UP主**：按 UP 主归类，发得多的排在前面
- 可选 1 天 / 3 天 / 7 天，「仅视频」或包含图文、转发、直播
- 选「全部」时显示 B 站原来的列表，和没装插件一样

## 安装

1. 在 [Releases](../../releases) 下载最新的 `bilisift-vX.Y.Z.zip` 并解压
2. 打开 `chrome://extensions`（Edge：`edge://extensions`），开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择解压出来的文件夹
4. 刷新 B 站，把鼠标放到顶栏「动态」上

## 隐私

- 只请求 `api.bilibili.com`，使用的是你浏览器里已有的 B 站登录状态，和 B 站网页本身的请求一样
- 设置、关注分组和视频分区的缓存只保存在本地的 `chrome.storage`，不会发送到任何第三方
- 不收集、不上传任何数据

## 说明

- 第一次使用「分区」时需要逐个查询视频分区，会慢几秒；查过的会缓存
- 关注的 UP 很多时，7 天范围最多读取约 50 页动态，超出部分会提示未显示
- B 站改版可能导致筛选栏挂不上去，欢迎提 issue

## 本地预览

`demo/index.html` 用虚构数据模拟了顶栏动态弹窗，直接用浏览器打开即可预览界面，不需要登录。
